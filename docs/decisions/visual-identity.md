# 연하장 시각 언어

## Decisions

- 화면은 한 가지 모습뿐이다. 먹색 테이블 위에 크림색 종이 엽서와 빨간 우표가 놓인 장면이고, 라이트/다크 전환은 두지 않는다.
- 색은 네 가지 계열만 쓴다. 주홍 빨강(`#c8322b`), 크림 종이(`#f8f1e4`, `#f3ead9`), 적갈색(`#5b2219`), 먹색(`#1d1816`). 분홍(`#f2a7b9`)과 코발트(`#2f5bd3`)는 반짝이 별 같은 작은 장식에만 쓴다. 새 요소도 이 안에서 톤온톤으로 맞춘다. 이 값은 shadcn semantic token(`background`, `foreground`, `card`, `primary` 등)에 넣어 쓰고, 화면마다 색을 따로 덮어쓰지 않는다.
- 종이와 우표 면에는 미세한 노이즈 질감을 깐다.
- 글꼴은 영문과 숫자에 Gloock, 한글과 본문에 Pretendard를 쓴다. 제목에는 같은 글꼴 묶음을 쓰되 한글은 Pretendard Bold로 표시하고, Gloock을 억지로 굵게 만들지 않는다.
- 양 그림은 직접 그린 SVG 실루엣 하나를 색만 바꿔 쓴다(크림 양에 검은 별무늬와 분홍 리본, 빨간 양, 은박 양 등). 외부 일러스트를 가져오지 않는다.
- 엽서 글은 모두 엽서 뒷면 형식으로 보여 준다. 왼쪽 위 `to. 세린`, 오른쪽 위 `happy new year`와 우표, 줄 그어진 본문, `from. 닉네임`, 아래쪽 양 행렬. 답장도 같은 형식에 빨간 안쪽 테두리를 두른다.
- 우표 가장자리는 톱니(구멍 뚫린) 모양이고 기울이지 않는다.
- 주요 행동은 크림색 알약 버튼(먹색 글씨, 빨간 Gloock 화살표)이다. 되돌릴 수 없는 버리기만 빨간 버튼을 쓴다.
- 화면 간 이동의 주요 입구는 겹쳐 쌓인 엽서·봉투(엽서 더미)다. 누르면 그 한 장이 위로 뽑혀 올라가며 다음 화면으로 간다.
- 뒤로 가기는 모든 하위 화면의 왼쪽 위 `←` 하나로 통일한다. 같은 화면에 처음으로 가는 입구를 둘 이상 두지 않는다.
- 내용을 숨긴 비공개 엽서는 엽서 모양을 유지한 채 본문 자리를 회색 줄로 가리고, 가운데에 연하게 비치는 빨간 자물쇠를 둔다.
- 잠금과 봉인은 밀랍 봉인(양이 찍힌 빨간 밀랍)으로 표현한다. 이모지 자물쇠는 쓰지 않는다.
- 내용이 적은 화면은 주요 내용을 세로 가운데에 두고 주요 행동을 화면 아래쪽에 둔다.
- 인터랙션마다 짧은 애니메이션을 둔다. 사용자가 움직임 줄이기를 켜면 애니메이션을 최소화한다.

## Boundaries

- 일반 UI(입력, 다이얼로그, 탭, 알림)는 [ui-composition](ui-composition.md)에 따라 shadcn 구성을 쓰고, 이 계약의 색·글꼴·질감만 입힌다. 우표, 엽서, 봉투, 우체통, 엽서 더미는 서비스의 핵심 표면이라 직접 그린다.
- 이 계약은 연하장 화면에 적용된다. 템플릿에 남아 있는 기존 계정 설정 화면을 새로 디자인하라는 뜻은 아니다.

## Why

세린이 고른 레퍼런스(민화풍 실루엣 동물, 빨간 우표, 크림 엽서, 검은 배경 위의 인쇄물)를 한 장면으로 묶은 결과다. 리뷰에서 여러 대안을 직접 비교했고, 색을 늘리거나 버튼을 버튼답게 만드는 쪽은 모두 이 장면을 깨뜨렸다. 새 화면을 만들 때 같은 비교를 반복하지 않도록 고정한다.

## Reconsider when

- 2028년 등 다른 해의 연하장으로 바꿀 때 (색과 동물은 바뀌고 종이·우표·엽서 문법은 남을 수 있다)
- Gloock이나 Pretendard의 웹폰트 배포가 끊길 때

## Still-rejected alternatives

- 귀여운 캐릭터 양과 둥근 카드 UI — 레퍼런스의 인쇄물 톤과 맞지 않았다.
- Bagel Fat One, Grandiflora One, 함렛(Hahmlet), Noto Serif 등 다른 한글·영문 조합 — 리뷰에서 직접 비교해 탈락했다.
- 양 옆이 파인 티켓 버튼, 우표 톱니 버튼, 봉투 버튼 — 톤이 튀거나 장식이 과했다.
- 우표를 뜯어서 이동하는 첫 화면 — 엽서 더미가 더 편지 같았다.
- 비공개 엽서를 적갈색 봉투나 `SECRET` 테이프로 가리기 — 엽서 벽에서 크기와 무게가 어긋났다.
- 처음으로 가는 입구를 화면 아래 엽서나 떠 있는 버튼으로 두기 — 화면마다 방식이 달라졌다.
