# 붉은 양의 연하장

2027 붉은 양의 해(丁未年) 온라인 연하장. 친구들이 로그인 없이 세린에게 새해 덕담을 엽서로 보내고, 세린이 답장한다. 엽서는 공개(모두의 엽서에서 누구나 읽음)나 비공개(보낸 친구와 세린만 읽음)로 보낼 수 있다. 모바일 우선.

연결된 자료 (구현 시 반드시 읽는다):
- [prototype.html](prototype.html) — 승인된 화면, 배치, 문구, 인터랙션과 애니메이션. 화면 구성과 문구는 이 파일이 정답이다. 상단 `screen`/`state` 선택으로 모든 화면과 상태를 볼 수 있다. 프로토타입의 숫자(27통, 11장 등)와 엽서 내용은 더미다.
- [visual-identity](../../decisions/visual-identity.md) — 색, 질감, 글꼴, 양 그림, 우표·엽서·봉투 표현, 버튼, 뒤로 가기, 애니메이션 규칙.
- [mailbox-access](../../decisions/mailbox-access.md) — 세린만 로그인하고 세린만 우체통·답장 기능에 접근하는 규칙.
- [ui-composition](../../decisions/ui-composition.md) — 일반 UI는 shadcn 구성과 semantic token으로.
- 용어는 [GLOSSARY.md](../../../GLOSSARY.md)를 따른다(엽서, 덕담, 우표, 답장, 모두의 엽서, 비밀 우체통, 세린의 우체통, 우체통 열기).

## 사용자에게 보이는 결과

**친구**
1. 첫 화면에서 빨간 양 우표(`here's to new beginnings`, 받은 엽서 총수)와 엽서 더미 세 장(비밀 우체통, 모두의 엽서, 엽서 쓰기)을 본다.
2. 엽서 쓰기에서 엽서 뒷면에 덕담과 닉네임을 적고, 우표 네 가지 중 하나를 붙이고, 공개나 비공개를 고른다. 비공개면 생일(MMDD)도 적는다. 우체통에 넣으면 엽서가 봉투에 들어가 날아가고, 보내기 완료 화면이 뜬다.
3. 모두의 엽서에서 모든 엽서를 최신순으로 본다. 공개 엽서는 덕담이 보이고 누르면 뒤집혀 답장이 보인다. 비공개 엽서는 잠긴 엽서로만 보인다.
4. 비밀 우체통에서 닉네임과 생일을 봉투에 적어 열면, 그 조합으로 보낸 비공개 엽서들과 답장을 본다.

**세린**
5. 첫 화면 우표의 `세린의 우체통 →`로 우체통 열기(로그인)에 들어가고, 세린의 우체통에서 받은 엽서를 답장 전, 답장 완료, 전체로 나눠 본다.
6. 엽서를 열어 답장을 쓰거나 고치고, 필요하면 엽서를 버린다.

## 승인된 범위

화면 9개와 그 상태(프로토타입 기준):

| 화면 | 상태 |
| --- | --- |
| 첫 화면 | 기본, 첫 엽서 전 |
| 엽서 쓰기 | 공개, 비공개(생일 칸 펼침), 입력 누락 안내, 보내기 애니메이션 |
| 보내기 완료 | 공개로 보냄, 비공개로 보냄 |
| 모두의 엽서 | 기본(공개·비공개 섞임), 엽서가 하나도 없을 때 |
| 비밀 우체통 | 기본, 찾지 못함, 여는 애니메이션 |
| 내 비밀 엽서와 답장 | 답장 있음, 답장 기다리는 중 |
| 우체통 열기 | 기본, 열리지 않음(로그인 실패), 여는 애니메이션 |
| 세린의 우체통 | 기본(탭 3개), 엽서가 하나도 없을 때 |
| 엽서와 답장 (세린) | 답장 쓰기, 답장 보기·고치기, 버리기 확인 |

함께 바꾸는 것:
- 기존 템플릿의 가입 화면(`/auth/sign-up`)과 가입 링크를 없앤다.
- 기존 템플릿 홈 화면과 상단 헤더(Sign in, Settings, Sign out)는 연하장 화면에서 보이지 않게 한다.
- 문서 언어를 한국어(`lang="ko"`)로, 페이지 제목을 연하장 이름으로 바꾼다.

## 수용 기준

브라우저로 확인한다. 모바일은 390px 폭 기준.

**첫 화면**
- AC1. 빨간 우표에 `here's to new beginnings`(양 위 아치), 양 그림, 반짝이 별 네 개, `2 0 2 7`, `세린에게 N통 도착`(N은 실제 엽서 총수)이 보인다. 엽서가 0통이면 `첫 엽서를 기다려요`가 보인다.
- AC2. 엽서 더미의 비밀 우체통, 모두의 엽서, 엽서 쓰기를 누르면 그 엽서가 뽑혀 올라간 뒤 각 화면으로 간다. 모두의 엽서에는 실제 공개 엽서 수가 보인다.
- AC3. 우표 오른쪽 위 `세린의 우체통 →`를 누르면, 세린이 로그인돼 있지 않으면 우체통 열기로, 로그인돼 있으면 세린의 우체통으로 간다.

**엽서 쓰기**
- AC4. 덕담(1–300자), 닉네임(1–10자), 우표 한 가지, 공개 여부가 모두 있어야 보낼 수 있다. 비공개일 때만 생일 칸이 나타나고, 실제로 있는 월일 네 자리(예: 0315, 0229 허용, 0230 거부)여야 한다. 빠진 항목이 있으면 보내지 않고 무엇이 빠졌는지 알려 주며 엽서가 흔들린다.
- AC5. 우표를 고르면 그 우표가 엽서 오른쪽 위 우표 자리로 날아가 붙는다.
- AC6. 보내면 엽서가 저장되고, 봉투 애니메이션 뒤 보내기 완료 화면이 뜬다. 보낸 엽서를 친구가 고치거나 지울 방법은 없다.

**보내기 완료**
- AC7. 우표 위에 `Happy New Year` 소인이 찍히는 애니메이션이 있다. 공개로 보냈으면 아래에 `모두의 엽서` 봉투가, 비공개로 보냈으면 `비밀 우체통` 봉투와 `닉네임 · 생일로 열어 볼 수 있어요` 안내가 보인다.

**모두의 엽서**
- AC8. 모든 엽서가 보낸 시각 최신순으로 두 줄로 보인다. 공개 엽서는 닉네임, 덕담, 우표가 보이고, 누르면 뒤집혀 답장이나 `답장을 쓰는 중이에요`가 보인다.
- AC9. 비공개 엽서는 본문 자리가 회색 줄로 가려지고 `from. ● ● ●`, 가운데 연한 자물쇠, `비밀 엽서 · 날짜`만 보인다. 누르면 `보낸 사람만 비밀 우체통에서 열 수 있어요.`가 나타난다.
- AC10. 비공개 엽서의 닉네임, 덕담, 생일, 답장은 이 화면을 여는 동안 서버 응답에 들어 있지 않다(브라우저 네트워크 응답으로 확인).
- AC11. 엽서가 하나도 없으면 `첫 엽서를 기다리고 있어요`와 `첫 엽서 쓰기`가 화면 세로 가운데에 보인다.

**비밀 우체통**
- AC12. 닉네임과 생일이 맞으면 봉인이 떨어지고 덮개가 열린 뒤, 그 닉네임과 생일로 보낸 비공개 엽서가 모두(여러 장이면 전부) 최신순으로 보이고, 각 엽서를 누르면 뒤집혀 답장이 보인다.
- AC13. 맞지 않으면 봉투가 흔들리고 찾지 못했다는 안내가 나오며, 어떤 엽서 정보도 서버 응답에 들어 있지 않다.

**세린 전용**
- AC14. 가입 화면과 가입 링크가 없고, Supabase 가입 API를 직접 호출해도 새 계정이 만들어지지 않는다.
- AC15. 세린의 이메일과 비밀번호로 우체통을 열면 우체통 문이 열리는 애니메이션 뒤 세린의 우체통으로 간다. 틀리면 우체통과 꼬리표가 흔들리고 안내가 나온다.
- AC16. 세린이 아닌 계정으로 로그인하거나 로그인하지 않은 상태에서는 세린의 우체통, 엽서와 답장(세린) 화면에 들어갈 수 없고, 답장 쓰기·고치기·엽서 버리기를 API로 직접 호출해도 거부된다.
- AC17. 세린의 우체통 위쪽에 답장 기다리는 엽서 수와 받은 엽서 수(공개·비공개 각각)가 실제 값으로 보이고, 탭 답장 전, 답장 완료, 전체로 목록이 나뉜다. 세린이 아직 열어 보지 않은 엽서에는 NEW 표시가 붙고, 한 번 열면 사라진다.
- AC18. 엽서를 열어 답장(1–300자)을 보내면 저장되고, 공개 엽서면 모두의 엽서에서, 비공개 엽서면 비밀 우체통에서 바로 보인다. 보낸 답장은 고칠 수 있고 고친 내용이 그대로 반영된다.
- AC19. 버리기를 누르면 확인 시트가 뜨고, 확인하면 엽서와 답장이 영구히 지워져 모두의 엽서와 비밀 우체통에서도 사라진다.
- AC20. 세린의 우체통에서 왼쪽 위 `←`를 누르면 첫 화면으로 가고, 로그인은 유지된다.

**공통**
- AC21. 첫 화면을 뺀 모든 화면 왼쪽 위에 `←`가 있고, 다른 처음으로 가는 입구는 없다(보내기 완료의 아래쪽 봉투는 다음 화면으로 가는 입구다).
- AC22. 390px 폭에서 가로 스크롤이나 겹침이 없고, 넓은 화면에서는 같은 모바일 레이아웃이 가운데에 놓인다. 내용이 적은 화면(보내기 완료, 비밀 우체통, 우체통 열기, 빈 상태)은 주요 내용이 세로 가운데, 주요 행동이 아래쪽에 온다.
- AC23. 글꼴은 영문·숫자 Gloock, 한글·본문 Pretendard로 표시된다.
- AC24. 운영체제의 움직임 줄이기를 켜면 애니메이션이 거의 즉시 끝난다.
- AC25. 비공개 엽서의 생일은 DB에 원문으로 저장되지 않는다(DB를 직접 조회해 확인).

## 확정된 제약과 근거

- 연하장 주인은 세린 한 명이다. 누구나 자기 연하장을 여는 구조는 범위가 크게 늘어나서 택하지 않았다. (사용자 확정)
- 엽서는 공개와 비공개 중 친구가 고른다. 공개 엽서는 생일 없이 닉네임만 받고 답장까지 공개된다. 비공개 엽서는 닉네임과 생일로만 열린다. (사용자 확정)
- 비공개 엽서도 모두의 엽서에 잠긴 엽서로 섞어 보여 준다. 보낸 사람 닉네임은 감춘다. (사용자 확정, 닉네임 감춤은 에이전트 기본값을 사용자가 유지)
- 친구는 보낸 엽서를 고치거나 지울 수 없다. 진짜 연하장처럼 한 번 보내면 끝이다. (사용자 확정)
- 세린은 답장을 언제든 고칠 수 있고 엽서를 버릴 수 있다. (사용자 확정)
- 비밀 우체통은 닉네임과 생일이 같은 비공개 엽서를 모두 보여 준다. 링크를 보관할 필요가 없어서 택했다. (사용자 확정)
- 세린만 로그인하는 구조는 [mailbox-access](../../decisions/mailbox-access.md)를 따른다. (사용자 확정)
- 데이터는 이미 연결된 Supabase 프로젝트에 저장한다. 비공개 엽서의 내용은 화면에서 숨기는 것이 아니라 서버가 내주지 않는다. (사용자 확정)
- 화면 모습은 [visual-identity](../../decisions/visual-identity.md)를 따른다. 다크 모드 전환은 없다. (사용자 확정)
- 용어는 엽서와 우체통으로 통일한다. 편지, 카드, 덕담 벽, 편지함, 주인, 로그인 같은 말은 화면에 쓰지 않는다(`우체통 열기`가 로그인이다). (사용자 확정)

## 가정 (바꿀 수 있음)

- 닉네임은 앞뒤 공백을 지운 뒤 글자 그대로 비교한다(대소문자 구분).
- 덕담과 답장은 최대 300자, 닉네임은 최대 10자다.
- 받은 엽서 총수와 공개 엽서 수는 버린 엽서를 빼고 센다.
- 엽서는 기간 제한 없이 언제든 보낼 수 있다.
- 세린의 우체통에는 로그아웃 버튼이 없다. 세린 본인 기기에서 쓴다는 전제다.
- 소인에는 날짜 없이 `Happy New Year`와 `2027`만 찍는다.
- 세린의 우체통 빈 상태의 `주소 복사하기`는 연하장 첫 화면 주소를 클립보드에 복사한다.
- 웹폰트(Gloock, Pretendard)는 외부 배포처에서 불러오거나 프로젝트에 포함한다. 어느 쪽이든 AC23만 만족하면 된다.
- 기존 템플릿의 `/settings`(프로필 표시 이름) 화면은 경로만 남기고 연하장 화면 어디에서도 연결하지 않는다.

## 범위 밖과 이유

- 새 엽서·답장 알림(이메일, 푸시) — 요청되지 않음.
- 친구의 엽서 수정·삭제 — 확정된 제약.
- 이미지·스티커 첨부, 우표 외 꾸미기 — 우표 선택으로 충분하다고 정했다.
- 다크 모드 전환 — 사용자가 필요 없다고 했다.
- 생일 대입 시도 제한, 스팸 방지, 신고·차단 — AGENTS.md 검증·리뷰 예산상 스펙이 요구하지 않은 보안 하드닝은 범위 밖.
- 세린 계정의 이메일 변경, 비밀번호 재설정, 로그아웃 — 요청되지 않음.
- 여러 해(2028년 등) 지원 — 요청되지 않음.

## 미뤄 둔 결정

없음.

## 남은 위험

- 생일은 366가지뿐이라, 닉네임을 아는 사람이 생일을 차례로 넣어 보면 비공개 엽서를 열 수 있다. 정말 숨겨야 할 내용이 생기면 시도 횟수 제한을 따로 정한다.
- 서로 다른 두 친구가 같은 닉네임과 같은 생일로 비공개 엽서를 보내면 서로의 엽서와 답장을 보게 된다.
- 외부 웹폰트 배포처가 느리거나 막히면 글꼴이 늦게 뜨거나 기본 글꼴로 보인다.
- 로그인한 상태의 세린 기기를 다른 사람이 쓰면 우체통이 그대로 열린다(로그아웃 버튼 없음).

## Setup before implementation

- Supabase Auth 새 가입 끄기 — 세린 외 계정 생성을 막는다(AC14) — 완료 조건: 앱 밖에서 프로젝트의 공개 키로 Supabase 가입 API를 호출하면 가입이 허용되지 않는다는 오류가 돌아온다.
- 세린 계정 생성 — 우체통 열기(AC15) — 완료 조건: Supabase 대시보드의 Users 목록에 세린의 이메일 계정이 보인다.
- 배포 환경에 세린의 이메일을 설정값으로 등록 — 세린 전용 확인(AC16) — 완료 조건: Vercel 프로젝트의 환경 변수 목록에 세린 이메일 값이 등록되어 있다.
